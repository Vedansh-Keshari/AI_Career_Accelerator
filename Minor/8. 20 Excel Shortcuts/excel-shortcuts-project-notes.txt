2. CHANGES MADE TO THE ORIGINAL .MD
-----------------------------------
2.1 CORRECTED (wrong or misleading in the original)
    a) Format Cells
       Original: Ctrl + T
       Now: Ctrl + 1
       Reason: Ctrl + T creates a Table, which the original also listed under
       "Create a Table".
    b) Add a new row or column (Ctrl + Shift + "+")
       Original: "after selecting it"
       Now: the new row appears ABOVE the selected row, and the new column
       appears to the LEFT of the selected column.
    c) Title count
       Original title says 20 shortcuts. The file actually lists 24 entries
       (Module 1: 7, Module 2: 8, Module 3: 4, Module 4: 5). All 24 are used.
    d) Add comments (Shift + F2)
       In current Microsoft 365 this adds a Note. A threaded Comment is
       Ctrl + Shift + F2. The entry is now named "Add a note".

2.2 ADDED (not in the original)
    - Explanations and worked examples for every command, using a sample
      Sales sheet (Date, Region, Product, Units, Revenue).
    - Extra tips: Alt, W, F, F to unfreeze; Ctrl + Home to return to A1;
      Ctrl + Y to redo; F5 as another way to open Go To; Go To Special;
      Ctrl + F for Find only; Ctrl + Shift + L to switch filter arrows on and
      off; F4 cycling reference types (A1, $A$1, A$1, $A1) inside a formula.
    - Clarifications: Alt + Down needs the list directly below the data with
      no blank row; Move Row needs Shift held while dragging the row border,
      otherwise the target is overwritten; Ctrl + R and Ctrl + D can also fill
      across a selected range.
    - MAX and LARGE: LARGE works for any rank (k = 1 equals MAX, not only the
      second or third largest), and duplicate values count separately.
    - Labels marking entries that are mouse actions or functions rather than
      key shortcuts: Move Row, Filter, Insert slicer, MAX and LARGE.
    - Everything in the app and the revision flowchart (device picker, Main
      page button, quiz, progress tracker).

2.3 REMOVED OR REPLACED
    - The incorrect "Ctrl + T" under Format Cells (replaced by Ctrl + 1).
    - The word "after" in the insert row/column entry (replaced by above / left).
    - The "20" count (replaced by the real count of 24).
    - The "Add comments" wording (replaced by "Add a note").
    - The original tab-spaced plain layout, replaced by structured modules.
    - No shortcut from the original was deleted. All 24 entries are kept.

2.4 RENAMED (wording only)
    - "Custom range selection" is shown as "Custom selection".
    - "Copy data from immediate left / up" is shown as "Copy from the left /
      above".
    - "drop-down list of already used data" is shown as "Pick from column list".
    - "TableDesign tab" is written as "Table Design tab".
    - "= large(range,rank)" is written as =LARGE(range, k).


3. LIMITS
---------
- Windows only. All keys are for Excel on Windows with a keyboard. Mac
  equivalents were not added because several differ and could not all be
  verified.
- Phones. Excel on a phone has no keyboard shortcuts, so on a phone the
  trainer is for studying and revision, not for practising the keys.
- Excel version. Names such as "Table Design" and the Note vs Comment behaviour
  follow current Microsoft 365. Older versions may differ.
- Progress is stored in the browser on the device being used. It does not sync
  between devices, and clearing browser data resets it.
- Quiz questions are a random set of 10 from the 24 entries, so each attempt
  differs. Options are the shortcut keys; there are no typed answers.
- Testing. The website was checked with an automated test (device picker,
  search, learn toggles, a full 10-question quiz, Main page button, flowchart,
  progress saving; 38 checks passed, no script errors). It was not tested on
  physical phones or on every browser.
- The document is a Claude Doc, not a pre-made Word file. Download it as Word
  (.docx) or PDF from the viewer if needed.
- The website and document are private to the account owner until shared.
- Four entries are not pure keyboard shortcuts (Move Row, Filter, Insert
  slicer, MAX and LARGE), so they are shown as actions or functions.
