## Data Transformation Cleaning and Preparing Data in Excel
1) Convert data into _Excel Table_ by using the shortcut: **Ctrl + T**
2) _Remove extra spaces_, use **TRIM** function to remove any other odd spaces
3) _Round numbers_ so they do not look ugly by using the **ROUNDUP** functionality
4) Add _geographical data_ wherever necessary
5) Remove duplicates by using the **Data tab**
