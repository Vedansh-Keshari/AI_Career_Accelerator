# Profile optimization checklist (Appendix)

- [ ] Professional photo, face fills about 60% of the frame
- [ ] Banner states who you help and how
- [ ] Headline 60-220 characters: role | who you help | 2-3 skills
- [ ] About: hook, proof with numbers, what you post about, how to reach you
- [ ] Custom profile URL
- [ ] Featured section: best post, a project, a proof link
- [ ] 15+ skills, top 3 pinned
- [ ] 3+ specific recommendations
- [ ] Each role has at least one measurable result
- [ ] Visibility: Open to Work (job seekers) / Creator mode (thought leaders) / contact info (professionals)
- [ ] 8+ posts a month
- [ ] 500+ connections
